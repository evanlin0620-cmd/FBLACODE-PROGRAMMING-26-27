# Turnout demo script (7 minutes)

A run-through in the order the FBLA rating sheet reads: user journey, rules shown in the UI, help, reports, accessibility. Start from a fresh data folder or after Settings → Example data → Reset, so the dates line up.

| Time | Beat | Clicks | What the judge should notice |
|---|---|---|---|
| 0:00 | Welcome | Open the app on the sign-in screen | The sign-up sheet writes itself in; once the last name lands, a green tally stroke closes the count (the Turnout mark). "Example data" is labelled. |
| 0:30 | Volunteer home | Try as a volunteer | Month title, next-shift ticket, hours ring counting up, "Dealt for you" with a match score and the reasons behind it. |
| 1:15 | Sign up and the waitlist | Find activities → Website Refresh Sprint → Join waitlist | A full shift puts you on the waitlist with your position; overlapping shifts are refused with a message that names the clash. |
| 2:00 | Add to calendar | Dashboard ticket → Add to calendar → Save | A real .ics file for Outlook, Google or Apple Calendar. |
| 2:20 | Reminder | Notifications | "Coming up: Thanksgiving Meal Prep", created at sign-in for shifts in the next 7 days, once each. |
| 2:40 | Log hours, with validation | My hours → Log hours → enter more hours than the shift lasted | The error says the shift's length; format and meaning are both checked. |
| 3:10 | Certificate | Get my certificate | Prints top to bottom; every certificate has a verification code. |
| 3:30 | Coordinator home | Log out → Try as a coordinator | Review stack (Approve / Send back with a reason), the month chart drawing in, stats counting up. |
| 4:20 | Fill a shift | Activities → Creek Cleanup → Suggested volunteers → Invite | Best-matched volunteers who haven't signed up, with their match and reason; one click sends the invite. |
| 5:00 | Reports | Reports → change Activity type | Totals tween to the new numbers; hover a month bar for its hours; Export CSV / Save as PDF. |
| 5:40 | Verify and outbox | Reports → Verify a certificate; account menu → Email outbox | The code checks out; the invite and reminder are in the simulated outbox. |
| 6:10 | Help | Help & questions → "how do I log my hours?" | Offline Q&A answers typed questions in plain words. |
| 6:40 | Accessibility | Tab through the sidebar; press ? | Visible focus rings, keyboard shortcuts, every status in words, reduced motion respected. |

If a step fails on stage, Settings → Example data → Reset restores the example in one click.
